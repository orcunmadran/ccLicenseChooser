How to Add a New Language?

If you want to add a new language (for example, Spanish), you'll need to:

1) Add a new translation file named es.json to the "locales" folder.
2) Add a new line { code: 'es', name: 'Español' } to the "availableLanguages" ​​array in the "js/main.js" file.
